### 🚀 Proyecto Semestral Destacado: InnovaTech Cargo

He diseñado y desplegado la arquitectura completa para el sistema logístico de **InnovaTech**, integrando un Frontend en React y un Backend de Microservicios con Spring Boot, todo orquestado y desplegado en la nube de AWS.

**Arquitectura y Tecnologías:**
- 💻 **Frontend:** React + Vite, Nginx Proxy (EC2).
- ⚙️ **Backend:** Microservicios con Java Spring Boot (Ventas y Despachos).
- 🗄️ **Base de Datos:** MySQL Server (Alojada en contenedor).
- ☁️ **Cloud (AWS):** VPC, EC2, Security Groups, Subredes Públicas y Privadas.
- 🐳 **DevOps:** Contenerización con Docker y CI/CD automatizado con GitHub Actions.
